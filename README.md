# 🛰️ Exoplanet Mission Control Hub

A unified, mission-control-style dashboard for tracking **active, upcoming, and legacy space telescopes** focused on **exoplanet discovery and characterization**.

Built for the **Exoplanet Watch (EPW)** community and anyone interested in how space-based observatories work together to study worlds beyond our solar system.

---

## 🌌 Overview

The Exoplanet Mission Control Hub brings together major space telescopes across NASA, ESA, and other agencies into a single, easy-to-navigate interface.

It provides:

* 📡 Mission status (Active, Upcoming, Retired)
* 📅 Key milestones (launch, mission start, end of operations)
* 🔭 Telescope roles in the exoplanet pipeline
* 🧠 Educational context for each mission
* 🔗 Links to official trackers and observation tools

---

## 🚀 Why This Exists

There is currently **no single place** to view all exoplanet-focused missions together.

This project aims to become:

> **“Mission Control for Exoplanet Science”**

Connecting:

* Discovery missions (like TESS)
* Follow-up observations (EPW, ground-based)
* Characterization (JWST, Hubble, CHEOPS)
* Future missions (Roman, PLATO, ARIEL)

---

## 🧭 Features

### 🟢 Mission Tabs

* **Active Missions** – Currently operating telescopes
* **Upcoming Missions** – Future launches and planned observatories
* **Retired Missions** – Legacy missions and data archives

### 🛰️ Mission Cards

Each mission includes:

* Name, agency, and status
* Launch date and mission timeline
* Orbit/location (LEO, L2, heliocentric, etc.)
* Role in exoplanet science
* EPW relevance
* Image of the spacecraft
* Links to official trackers or dashboards

### 🔗 Tracker Integration

Where available, missions link to:

* Live observation trackers (JWST, Hubble)
* Sky position tools
* Official mission dashboards
* Observation schedules
